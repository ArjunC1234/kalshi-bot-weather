# Legacy Experimentation

This folder archives all work from the first chapter of the project.

## Contents

- Prototype weather probability scripts.
- Old backtesting and strategy simulation scripts.
- Old Supabase collector implementation.
- Historical local `backtest_data/`.
- Generated `output/` reports and charts.
- Old server bot experiments and systemd files.

## Usage

Legacy files are preserved for reference and reproducibility. New development should not happen here unless the goal is to recover or inspect old behavior.

## Relationship To Next-Gen

Useful ideas can be copied into `next-gen/`, but old scripts should not be imported directly by new modules.
